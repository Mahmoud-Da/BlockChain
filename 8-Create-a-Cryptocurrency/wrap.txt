# Hadcoin (Module 2) 
# 1 — Goal & high-level overview

* Create a cryptocurrency called **Hadcoin** by extending the Module 1 blockchain implementation.
* Implementation broken into **three parts**:

  1. Build the blockchain structure adjusted for a currency.
  2. Mining: accept transactions and mine blocks (including miner reward).
  3. Decentralize: create a network of nodes and implement consensus.

# 4 — Imports (exact code + purpose)

Correct, minimal import block to start `Hadcoin.py`:

-------------------code----------------------
from datetime import datetime
import hashlib
import json
from flask import Flask, jsonify, request
import requests
from uuid import uuid4
from urllib.parse import urlparse
-------------------code----------------------

Purpose of each:

* `datetime` — timestamp mined blocks.
* `hashlib` — cryptographic hashing (SHA-256) for block hashes.
* `json` — format transactions and blocks.
* `Flask, jsonify, request` — create web API endpoints and handle JSON requests/responses.
* `requests` — HTTP client used to talk to other nodes (consensus checks, chain fetching).
* `uuid4` — generate a unique node identifier/address (e.g., miner reward address).
* `urlparse` — parse node URLs when registering nodes in the network.

Quick node id example:

-------------------code----------------------
node_identifier = str(uuid4()).replace('-', '')
-------------------code----------------------
