## Tools Required

1. **Ganache**

   * Local blockchain for Ethereum development.
   * User-friendly interface.
   * Features:

     * Blocks and transactions overview.
     * JavaScript Ethereum blockchain implementation.
   * Installation:

     * Download from Truffle’s official site (not the food “ganache”).
     * Available for Mac, Windows, Linux.
     * Provides TX count and mining simulation.

2. **MyEtherWallet (MEW)**

   * Ethereum-based wallet.
   * Used for buying and selling Hadcoins in this module.
   * Installation:

     * Download latest release from GitHub.
     * Use the ZIP file → contains `index.html` for local use.
     * Place in course folder (Blockchain A–Z / Module 3).
   * Key Points:

     * Not a bank; fully decentralized.
     * Users are solely responsible for private keys and passwords.
     * Losing private keys = permanent loss of funds.
     * Risk of phishing → entering private keys on fake websites will lead to theft.
   * For this course: only simulated Hadcoins (no real monetary value).

3. **Solidity (via Remix IDE)**

   * Language used for smart contract development.
   * No separate installation required.
   * Access through browser at **Remix Solidity IDE**.
   * Features:

     * Write, compile, and deploy smart contracts.
     * Create new file `hadcoinsico.sol`.
     * Contract title: *Hadcoins ICO (Initial Hadcoin Offering)*.

# Smart Contract Implementation: Initial Hadcoins Offering (IHCO)

## Step 1: Solidity Compiler Setup

* Start by specifying the Solidity compiler version.
* Example: `pragma solidity ^0.4.11;`
* Version used: **0.4.11** (other versions may also work).

---

## Step 2: Creating the Contract

* Contracts in Solidity are declared using the `contract` keyword.
* Example:

  -------------------code----------------------

  contract hadcoin_ico {
      // contract definition
  }
  -------------------code----------------------

* Brackets `{ }` define everything inside the contract.
* This marks the beginning of the **first Solidity smart contract**.

---

## Step 3: Public vs Private Variables

* **Public variables**: Accessible by anyone (inside and outside the contract).
* **Private variables**: Accessible only within the contract.
* ICOs require **transparency**, so key values are public.

---

## Step 4: Defining Public Variables

### 1. Maximum Number of Hadcoins

* Represents the total supply of hadcoins available for sale.
* Public variable because an ICO is public like an IPO.
* Data type: `uint` (unsigned integer, cannot be negative).
* Default range: 0 → 2^32 – 1 (approx. 4.3 billion).
* Example declaration:

  -------------------code----------------------

  uint public max_hadcoins = 1000000;
  -------------------code----------------------

* Value initialized to **1,000,000** (the total supply).

---

### 2. Conversion Rate (USD to Hadcoins)

* Defines how many hadcoins equal 1 USD.
* Example value: **1 USD = 1000 hadcoins**.
* Public variable for transparency.
* Example declaration:

  -------------------code----------------------

  uint public usd_to_hadcoins = 1000;
  -------------------code----------------------


---

### 3. Total Hadcoins Bought

* Tracks how many hadcoins have been purchased by investors during the ICO.
* Starts at **0**, since no tokens are bought at the beginning.
* Public variable for transparency.
* Example declaration:

  -------------------code----------------------

  uint public total_hadcoins_bought = 0;
  -------------------code----------------------


---

## Summary of Variables

1. `max_hadcoins = 1000000` → total supply.
2. `usd_to_hadcoins = 1000` → conversion rate.
3. `total_hadcoins_bought = 0` → counter that updates during sales.

---
